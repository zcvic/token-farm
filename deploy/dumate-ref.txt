#        · token：GET https://www.dumate.cn/api/dumate/app/token/get
#          → {result: {token, expired_at}}；备选域 console.bce.baidu.com，
#          token 与域无关。进程内缓存，提前 5 分钟刷新，解析失败按 50 分钟
#          兜底。→ server/platforms/dumate/client.py
#        · 对话：POST https://dumate-svc.baidu.com/gateway/apis/v1/chat/completions
#          头 Authorization: Bearer <token>、X-Dumate-Client-Type: web、
#          X-Dumate-Account-Id: global；标准 OpenAI SSE，含 reasoning_content。
#          → server/platforms/dumate/client.py + adapter.py
#        · 签到：GET /api/dumate/points/loginBonusInfo、
#          POST /api/dumate/points/loginBonus。→ client.checkin / adapter.checkin
#        · 积分：GET /api/dumate/points/quota_overview?clientType=desktop&
#          timezone=Asia%2FShanghai → totalPoints / usedPoints / subscription /
#          incremental / isSubscribed / modelThrottleInfo。
#        · 模型目录三级降级：桌面端 opencode.json → 进程缓存 → 包内
#          catalog.json 快照。对外模型名加 `dumate/` 前缀（参考仓是裸名）。
#        · 业务码：HTTP 200 仍要读 `code`（code=0 且 success!=false 才成功）；
#          登录失效码 10001 / 10006 → 强刷一次 token 再重试。
#        · max_tokens：目录里的 limit.output 是客户端展示值，真值见
#          constants.OUTPUT_CAPS（例如 model-text 393216），按真值钳制，
#          避免上游 400。
