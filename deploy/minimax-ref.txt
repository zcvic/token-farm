# ---- 2026-11 首次接入（0.2.9）
#
#      已取（按能力，不是逐行移植）：
#        · OAuth 设备码：
#          POST {account}/oauth2/device/code
#            client_id=mcode-public、scope=agent.default、
#            audience=agent-backend、PKCE S256；
#          POST {account}/oauth2/token
#            grant_type=urn:ietf:params:oauth:grant-type:device_code；
#          刷新 grant_type=refresh_token。refresh token 是**一次性**的：
#          换发后旧的立即作废，必须**先落盘再使用**。
#          → server/platforms/minimax/client.py + store.py + adapter._token_for
#        · 双区站点：cn = account.minimax.cn / agent.minimax.cn /
#          agent.minimaxi.com（fallback agent.minimax.cn）/ www.minimaxi.com；
#          global = account.minimax.io / agent.minimax.io / platform.minimax.io。
#          → constants.SITES
#        · 对话：POST {llm}/mavis/api/v1/llm/v1/messages，Anthropic Messages
#          形状；头 Authorization: Bearer、x-api-key: sk-xxx、
#          User-Agent: MiniMaxAgent、X-Mavis-Agent-Id: main、
#          X-Mavis-Timezone-Offset、X-Mavis-Session-Id、
#          anthropic-version: 2023-06-01、accept-encoding: identity。
#          必须要求不压缩，否则上游按 gzip 成员缓冲，首字等到结束。
#          → client.chat_headers / open_chat；请求 / 响应 / SSE 双向翻译在
#            translate.py。
#        · 模型目录：GET {llm}/mavis/api/v1/models?region=cn&buildEnv=prod
#          → providers[providerId=minimax].config.models（可带 / 不带 Bearer）。
#          → catalog.parse_models
#        · 账号接口签名：yy + x-signature，SIGN_SECRET 见 constants。
#          yy = md5(encodeURIComponent(path+query) + "_" + bodyJson(或 "{}")
#                   + md5(str(now_ms)) + "ooui")；
#          x-signature = md5(ts + secret + body)，GET 不含 body。
#          query 固定带 device_platform=mcode、biz_id=3、app_id=3001、
#          version_code=22201、unix、timezone_offset、sys_language、lang、
#          device_id=0、os_name、browser_name=mcode、user_id、client=mcode。
#          → client.signed_request
#        · 身份 / 会员：GET {agent}/v1/api/user/info；
#          POST /matrix/api/v1/user/get_user_extra_info、
#          POST /matrix/api/v1/commerce/get_membership_info。
#        · 签到：GET /minimax-cloud/api/v1/signin/status、
#          POST /minimax-cloud/api/v1/signin/claim，
#          query device_platform=web、is_desktop=1、desktop_version=0.6.12。
#        · 积分明细：GET /minimax-cloud/api/v1/credit/details
#          （page_number / page_size / include_expired）。
#          条目：credit_type（1 / 2 为积分池，其余忽略）、granted_amount /
#          remaining_amount（**带千分位的字符串**）、expire_at_ms（毫秒）。
#          → adapter._ledger 归一成 {'amount', 'expire_at', 'label'}，
#          amount 是剩余、expire_at 是 epoch 秒（与前端契约一致）。
#          内部契约写错不会报错，只会让界面「积分有效期」整列静默变空。
#        · 套餐窗口：GET {platform}/backend/account/token_plan/remains_percent，
#          回退 GET {platform}/v1/api/openplatform/coding_plan/remains，
#          需要 X-Group-Id。→ client.plan_quota / parse_plan
#        · 模型快照：MiniMax-M3.1-Flash-Preview、MiniMax-M3
#          （1048576 / 524288，text/image/video）、MiniMax-M2.7、
#          MiniMax-M2.7-highspeed（200000 / 128000，text）。
#
#      有意不跟：
#        · 不引入 OpenCode 插件、它的本地文件布局与自动更新逻辑。
#        · 不接管 MiniMax 官方 CLI 的本地登录态（没有「从本机导入」）。
#        · 不把参考包的嵌套重试 / 状态机搬过来；选号、冷却、重试在
#          adapter.py，按 token-farm 的口径实现。
#
# ---- 2026-11-20 国际站补两处漏项（0.2.9 里已有，本仓库此前没落）----
#   · 国际站跨站 307：agent.minimax.io 在 Akamai 后面，中国大陆出口的请求
#     会被 307 到 agent.minimaxi.com（X-From: ak），国内站拒绝国际站 token。
#     httpx 默认不跟重定向，表现为 HTTP 307 / 400；跟了会把国内站的
#     "invalid access token" 误判成登录失效。现在 client._guard_redirect
#     认出跨站 Location，报 cross_site_redirect，并提示给账号绑境外代理；
#     不消耗 refresh token。OAuth / 账号 / 模型 / 对话 / 套餐 / 签到同一口径。
#   · 国际站会员接口 404：/matrix/api/v1/user/get_user_extra_info 与
#     /matrix/api/v1/commerce/get_membership_info 都回 404（上游 #666）。
#     此时套餐是「未知」，不是 Free：fetch_membership 返回 {}，
#     用量页把 entitlement 留空，不记 membership 错误。
#
